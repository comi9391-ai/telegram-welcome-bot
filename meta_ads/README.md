# 워프파이프 Meta 광고

자동매매 홍보 영상을 워프파이프 이름으로 올리고, "신청하기"를 누르면 이름·연락처·사용 중인 거래소를 받는 리드 광고 세팅.

## 1. 광고에 뜨는 이름을 워프파이프로

광고 왼쪽 위에 뜨는 이름은 광고 계정이 아니라 **광고에 연결된 페이스북 페이지 이름**이다. 인스타그램 노출분은 연결된 인스타 계정 이름이 뜬다.

- 새 페이지를 만드는 게 빠르다. 기존 페이지 이름 변경은 Meta 검토가 붙고, 성격이 크게 바뀌는 변경(트레이딩 채널 → 개발사)은 거절되기도 한다.
  - facebook.com/pages/create → 이름 `워프파이프`, 카테고리 `소프트웨어 회사`
  - 페이지 문구는 [`warp_pipe_page.md`](warp_pipe_page.md) 그대로 붙여 넣으면 된다.
- 비즈니스 설정 > 계정 > 페이지에서 워프파이프 페이지를 비즈니스 포트폴리오에 추가하고, 광고 계정에 권한을 준다.
- 인스타그램도 워프파이프로 보이게 하려면 인스타 계정을 새로 만들어 페이지에 연결한다.
- 광고 단위 편집 화면 > "아이덴티티"에서 페이스북 페이지와 인스타 계정을 워프파이프로 고른다. 스크립트를 쓰면 `META_PAGE_ID`가 이 역할을 한다.

## 2. 신청서 (인스턴트 양식)

| 항목 | 형식 |
|---|---|
| 이름 | 페이스북 프로필에서 자동 입력 |
| 연락처 | 페이스북 프로필에서 자동 입력, 수정 가능 |
| 사용 중인 거래소 | 객관식: 바이낸스 / 바이비트 / OKX / 비트겟 / 업비트 / 빗썸 / 기타·아직 없음 |

- 양식 유형은 **"더 높은 의도"** 추천. 제출 전에 확인 화면이 한 번 더 떠서 장난 신청이 줄어든다.
- 개인정보처리방침 URL이 없으면 양식 자체를 만들 수 없다. 랜딩페이지 전이라도 방침 페이지 하나는 먼저 필요하다.
- 접수 내역은 Meta 비즈니스 수트 > 모든 도구 > 인스턴트 양식에서 CSV로 받거나, 아래 `leads` 명령으로 받는다. 접수는 90일만 보관된다.

## 3. 스크립트로 한 번에 올리기

```bash
pip install requests
cp meta_ads/.env.example meta_ads/.env   # 값 채우기
set -a; . meta_ads/.env; set +a

# 실제로 보내기 전에 보낼 내용만 확인
python meta_ads/launch_ad.py launch --video 광고영상.mp4 --dry-run

# 영상 업로드 → 신청서 → 소재 → 광고 (일시중지 상태로 생성)
python meta_ads/launch_ad.py launch --video 광고영상.mp4

# 접수 내역 CSV로 받기
python meta_ads/launch_ad.py leads --form-id <신청서ID> --out leads.csv
```

광고는 항상 **일시중지** 상태로 만들어진다. 광고관리자에서 미리보기를 확인하고 직접 켜야 비용이 나간다. 캠페인과 광고 세트(예산·타겟)는 광고관리자에서 먼저 만들어 두고 그 광고 세트 ID를 넣는다. 캠페인 목표는 "잠재 고객", 전환 위치는 "인스턴트 양식"이어야 한다.

광고 문구와 신청서 문구는 `launch_ad.py` 위쪽 `AD_COPY`, `LEAD_FORM`에서 고친다.

## 4. 올리기 전에 확인할 것 (심사 거절 위험)

이번 영상(51초, 360×640)은 그대로 올리면 거부될 가능성이 높다.

- **암호화폐 거래 광고는 Meta 사전 승인 대상.** 자동매매 봇·트레이딩 프로그램 홍보는 Meta 암호화폐 광고 정책에 걸린다. 승인(라이선스 증빙 제출) 없이 올리면 거부되고, 반복되면 광고 계정이 제한된다.
- **"하루만에 자산 21% 증가" 장면.** 단기간 수익을 보여주는 표현은 금융 광고에서 과장·오해 소지로 거부되는 대표 사유다.
- **실존 트레이더 사진.** 인물(니콜라스 다바스, 리처드 데니스 등) 얼굴을 허락 없이 쓰면 초상권과 "유명인 사칭" 정책에 걸릴 수 있다.
- **50배 레버리지 노출.** 고위험 금융상품 표현이라 검토가 더 엄격해진다.
- **해상도.** 360×640은 너무 낮다. 세로 영상은 1080×1920을 권장한다. 원본이 있으면 원본으로 올리는 게 좋다.

광고 문구에는 수익 보장 표현을 빼고 손실 위험 문구를 넣어 두었다. 영상 쪽은 위 항목들을 손보는 게 승인 확률을 가장 크게 올린다.
